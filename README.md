#Company Contacts Comparison

This project shows how to use IComparable and IComparer in .NET using C#
It contains a Windows Forms project, which loads a list of companies in random order.

<img width="579" height="230" alt="image" src="https://github.com/user-attachments/assets/9b2b096e-85c6-42e1-bcfc-2ecc6526a20a" />

The exercise is to implement the missing IComparer<Company> classes to enable sorting on different attributes of the Company objects.

This project includes two branches
- Master which has the template for the exercise
- Solution which has the fully implemented IComparer<Company> classes
